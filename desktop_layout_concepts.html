Option A — Sidebar nav, single wider column. Closest to the phone app: same four sections, same stacked trip cards, just with room to breathe instead of a cramped phone-width column. Lowest-risk change, and the fastest to build.

Option B — Top nav bar, trip cards side by side. Feels more like a dedicated desktop app. Uses the width to show more at once — on a wide-enough window all three trips are visible without scrolling. A bigger visual departure from the phone version, a bit more CSS work.
